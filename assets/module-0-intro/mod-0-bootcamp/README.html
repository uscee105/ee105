🐍 EE105 Lab 0 — Python Bootcamp

In this course, we'll use Jupyter Notebook — an interactive coding environment where you can write and run Python code, see results instantly, and add notes alongside your code.

To run Jupyter, we'll install Anaconda — a free software package that includes Python, Jupyter, and all the scientific libraries you'll need (NumPy, Matplotlib, etc.).

Follow these simple steps to get started.

🚀 First Time Setup

Run this once to install everything you need.

🪟 Windows
1 Double-click:
Windows/setup_and_run.bat
2 Wait for installation (~15 min)
3 When complete, close the window and run it again
🍎 Mac
1 Right-click → Open:
Mac/setup_and_run.command
2 Click "Open" on any security prompts
3 Follow the terminal prompts
What this does: Downloads and installs Anaconda (Python + Jupyter + scientific packages), then launches the notebook.

📓 Opening Notebooks (After Setup)

Use one of these methods each time you want to work on the notebooks:

Option 1: Use the Launcher Files

🪟 Windows
Double-click:
Windows/launch_notebook.bat
🍎 Mac
Double-click:
Mac/launch_notebook.command

Option 2: From Applications

Windows: Search for "Jupyter Notebook" in Start Menu
Mac: Open Anaconda Navigator → Click Launch under Jupyter Notebook

📖 Using Jupyter Notebook

1 A browser window will open showing your files
2 Click on any .ipynb file to open it
3 To run a cell: click on it and press Shift + Enter (runs and moves to next cell) or Ctrl/Cmd + Enter (runs and stays on cell)
4 Run cells from top to bottom in order

❓ Troubleshooting

Mac: "Cannot be opened because it is from an unidentified developer"

Right-click the file → select "Open" → click "Open" in the dialog.

Windows: Nothing happens when I double-click

Make sure you've unzipped the folder first. If you're viewing files inside a .zip file, the scripts won't work.

Jupyter opens but I don't see my files

Use the launcher files from this folder. They open Jupyter in the correct directory.
