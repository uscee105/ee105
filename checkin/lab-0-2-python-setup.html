🐍 EE105 Lab 0.2 — Python Bootcamp

In this course we'll use Python to analyze data and (later on) talk to your Arduino boards. You'll write and run Python inside VS Code, using interactive Jupyter notebooks — documents that mix runnable code, results, and notes in one place. Python itself is managed by Anaconda.

Part A — at home: install two apps (big downloads).
Part B — at home: create your course Python environment (three commands).
Parts C & D — in the lab: run the notebooks and submit your work.

⚠️ Do Parts A and B at home, before the first lab. Together they take about 30 minutes and need ~5 GB of free disk space. If you arrive without them, you'll spend the lab session installing software instead of learning Python.

🧪 Part B — Create Your Course Environment (At Home)

A Python environment is a named, self-contained copy of Python plus only the packages you choose to install into it. We'll create one called ee105 and use it for every lab this semester.

1Open a terminal
🪟 Windows
Open the Start menu, type Anaconda Prompt, and open it. (Not the regular Command Prompt!)
🍎 Mac
Press Cmd + Space, type Terminal, and press Enter.
The line should start with (base) — that means Anaconda is working.
2Run these three commands, one at a time

Copy each line, paste it into the terminal, press Enter, and wait for it to finish before the next one.

Create the environment:

conda create -n ee105 python=3.12 -y

Step inside it — the (base) at the start of the line becomes (ee105):

conda activate ee105

Install the packages this course needs:

conda install numpy matplotlib sympy ipykernel nbconvert -y
3See what you just built (optional)
If you'd like to see your new environment visually, open Anaconda Navigator (from the Start menu / Applications), click the Environments tab, and select ee105. You'll see the packages you just installed.
A fresh environment starts empty — Python can't use NumPy, Matplotlib, or any other package until you install it. That's why Step 2 exists, and it's how you'll add any new tool we need later in the course.

❓ Troubleshooting

Windows: "conda is not recognized"

You're in the regular Command Prompt or PowerShell. Close it and open Anaconda Prompt from the Start menu instead.

Mac: "conda: command not found"

Quit Terminal completely (Cmd + Q) and reopen it. If it still doesn't work, re-run the Anaconda installer.

Windows: installer complains about spaces in the install path

If your Windows username contains a space, the installer may warn about it. Change the install location to C:\anaconda3 and continue.

ee105 doesn't appear in the kernel list

Make sure Part B finished without errors. Then in VS Code press Ctrl/Cmd + Shift + P, type "Developer: Reload Window", press Enter, and click Select Kernel again.

Cells fail with "ModuleNotFoundError: No module named 'numpy'"

The notebook is running on the wrong kernel. Click the kernel name in the top-right corner and switch to ee105.

Which files do I upload, and where are they?

The two files ending in .ipynb inside your unzipped mod-0-Lab2-python folder — the tutorial notebook and the Questions notebook. In VS Code you can right-click a notebook in the sidebar → Reveal in Finder / File Explorer to find them. Save (Ctrl/Cmd + S) before uploading.

Checkpoint cells say I'm not registered

Scroll up and run the register cell (with your real name and USC email) near the top of the notebook. If you restarted the kernel, run it again — your already-passed checkpoints are remembered.

I don't see the notebook files in VS Code

You probably opened the wrong folder, or you're still inside the zip file. Unzip first, then File → Open Folder… and select the extracted mod-0-Lab2-python folder.
